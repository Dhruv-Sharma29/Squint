# Squint

### Copy code from any screen. Paste code that runs.

The screen-OCR app for programmers on macOS. Squint keeps the indentation, blank lines and closing brackets that other OCR tools throw away.

## You've been here before

You pause a tutorial at 12:48. The code is right there on screen, and you can't select it.

So you reach for an OCR tool, and paste back a flat wall of text. The indentation is gone. Every line holding a lone `}` has vanished. `item[key]` became `item[keyl`, and `groupBy(items)` gained a space. For Python, lost indentation isn't cosmetic: it's a different program.

**Squint is screen OCR built for code.** Press **⌘⇧2**, drag over the code, paste. What you get is what was on screen.

## Install

```sh
brew tap dhruv-sharma29/squint https://github.com/Dhruv-Sharma29/Squint
brew install dhruv-sharma29/squint/squint
brew services start squint     # start now and at every login
```

Homebrew builds Squint on your Mac in about 20 seconds, so there are no Gatekeeper warnings. It needs macOS 14 or later and Xcode or the Command Line Tools. On first use, allow Squint under **System Settings › Privacy & Security › Screen Recording**. More options, including building from source, are in the [installation guide](docs/installation.md).

## Use it

| To | Do this |
|---|---|
| Copy code from the screen | **⌘⇧2**, then drag over it |
| Copy prose or other languages | Turn **Code Mode** off in the menu |
| Read a screenshot already on the clipboard | **Read Clipboard Image** in the menu, or `open "squint://clipboard"` |
| Trigger it from another app | `open "squint://capture"` (examples for [Raycast, Alfred and Shortcuts](docs/usage.md#links-and-automation)) |
| Script it | `squint screenshot.png \| pbcopy` |

**Tip:** start the selection at the code's left margin, since indentation is measured from the leftmost line. More in the [usage guide](docs/usage.md).

## Private by design

- Recognition uses Apple's on-device Vision framework. Squint makes **no network requests**.
- Each screenshot exists only as a temporary file, and is **deleted as soon as it has been read**.
- No account, no analytics, no crash reporting. The only permission it asks for is Screen Recording.

## Under the hood

Vision returns boxes of text. Squint places them on a line grid, turns left edges into indentation measured in character widths, and checks the pixels wherever Vision saw nothing. Where it finds ink, it restores the closing bracket for whatever is still open. It also fixes Vision's typical misreads of code, such as `{` read as `1` and `]` read as `l`. Every repair is deterministic, unit-tested, and explained in [How it works](docs/architecture.md).

## What's next

- **Settings:** a custom shortcut, launch at login, and a language picker. Vision reads 33 languages on macOS 27, including Hindi.
- **Even better code capture:** removing line-number gutters, choosing the repair that actually parses, and stitching scrolled captures into one file.
- **One-command install** and signed builds.

The plan, with success metrics, is in the [roadmap](docs/roadmap.md).
